# Estructura de carpetas para proyecto DaVinci Resolve

Crea la siguiente estructura de carpetas dentro de `F:\IRAOLA LABS`:

1. Crea una carpeta principal llamada `Primer_Proyecto_DaVinci`.
2. Dentro de esta carpeta, crea las siguientes subcarpetas:

   - `01_Footage`
   - `02_Audio`
   - `03_Graphics`
   - `04_Proxies`
   - `05_Cache`
   - `06_Exports`
   - `07_Backups`

Verifica que todas las carpetas hayan sido creadas correctamente y respeten exactamente los nombres indicados.
